# Communities and Crime

Explore regression on the UCI Communities and Crime dataset, with missing-value handling, regularisation, tree ensembles and diagnostic plots. Associations in these historical aggregate data are not causal explanations or individual predictions.

[Open the notebook](communities-crime.ipynb).

## Files and setup

The original input files are supplied as ZIP archives beside the notebook. Extract each archive into this same folder before running the notebook; extraction restores the original filename expected by the code. Install the shared dependencies from the repository root, then open this notebook with its own folder as the working directory. The notebook and saved outputs are copied unchanged from the local practice project; no new execution was performed.

## Evaluation context

The notebook preserves the original model comparisons and saved outputs. Scores describe this experiment and split, not independently established generalisation to new populations.
